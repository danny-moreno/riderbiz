# RiderBiz

RiderBiz es una plataforma independiente dirigida inicialmente a repartidores autónomos multioperador.

## Propósito

Reducir trabajo improductivo, organizar la jornada y ayudar al profesional a comprender su productividad y rentabilidad.

## Estado

Proyecto en fase de fundación de ingeniería y construcción de RiderBiz V1.

## Principios iniciales

- El problema y la evidencia preceden a la tecnología.
- RiderBiz complementa las plataformas obligatorias de los operadores.
- La V1 evitará funcionalidades no respaldadas por evidencia.
- La arquitectura debe ser evolutiva, pero no sobredimensionada.
- No se utilizarán datos personales reales durante el desarrollo.
- Cada funcionalidad deberá vincularse con una evidencia, decisión o hipótesis.
